## Getting Started

**Getting Started** covers how to install, run, and configure `sombra`.  
Use it when you apply templates or scaffold new projects.

## What You'll Learn

- How to install `sombra`
- How to generate new projects from templates
- How to use `sombra-cli` itself as a Go project template
- How to create and manage the `sombra.yaml` file
- How to update existing projects from updated templates

## Start Here

- [Installation](installation.md) — Install `sombra` with Go, a prebuilt binary, or from source.
- [Use sombra-cli as a Template](use-sombra-as-template.md): scaffold a new Go CLI from this repository.
- [`sombra.yaml` file](../cli/sombra-file.md) — Configure how your project applies one or more templates.
- [CLI Commands](../cli/commands.md) — Reference for all `sombra` commands and flags.
