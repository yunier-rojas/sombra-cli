## Getting Started

The **User Guide** covers how to install, run, and configure Sombra CLI.  
Use it when you apply templates or scaffold new projects.

## What You'll Learn

- How to install Sombra CLI
- How to generate new projects from templates
- How to create and manage the `sombra.yaml` file
- How to update existing projects from updated templates

## Start Here

- [Installation](installation.md) — Install Sombra with Go, a prebuilt binary, or from source.
- [Sombra File](sombra-file.md) — Configure how your project applies one or more templates.
- [CLI Commands](commands.md) — Reference for all Sombra commands and flags.
